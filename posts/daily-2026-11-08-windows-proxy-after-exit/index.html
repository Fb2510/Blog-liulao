关掉 Clash 后电脑上不了网？先检查 Windows 的代理设置

六佬2026-11-08— 次阅读
网络教程

关掉 Clash 或 Clash Verge Rev 后，Wi-Fi 明明连着，电脑却打不开网页，可以先看看 Windows 的“使用代理服务器”开关。如果客户端已经退出，系统还保留着它的代理设置，部分软件就可能继续往已经停止工作的程序发送请求。

六佬建议先按下面的顺序检查，每做一步就试一次网页。本文以个人电脑的 Windows 11 为例，先判断问题出在哪里，再调整对应设置。

第一步：看看是不是只有这台电脑有问题

准备两三个平时不用代理也能打开的网站，分别在电脑上试一下。再让手机连接同一个 Wi-Fi，暂时关闭手机移动数据，用相同的网站比较。

  • 手机能打开，电脑在退出客户端后打不开：优先检查电脑上的代理设置。
  • 手机和电脑都打不开：先确认 Wi-Fi、路由器和宽带连接是否正常。
  • 只有一个网站打不开：换其他网站比较，暂时不能判断整台电脑已经断网。

这里要测试的是原本可以直接访问的网页。关闭代理后，某些必须通过代理才能访问的网站仍打不开，并不能说明恢复失败。

第二步：在客户端里关闭系统代理，再正常退出

如果客户端还能启动，可以重新打开它，找到“系统代理”开关，将它关闭，再通过软件菜单正常退出。随后重新打开浏览器测试。

这样做是为了让软件有机会收回自己改过的设置。仅关闭主窗口是否会退出程序，要看客户端的设置；操作后也可以看看任务栏右下角是否仍有它的图标。

如果软件已经卸载、无法打开，或者这样做后仍不能上网，继续检查 Windows 的设置。Clash Verge Rev 官方常见问题也列出了这一情况：异常退出后，系统代理可能仍然开启。官方问题说明

第三步：检查 Windows 的手动代理开关

先拍下当前设置，方便需要时恢复。然后按这个顺序操作：

  1. 打开 Windows“设置”。
  2. 进入“网络和 Internet”，打开“代理”。
  3. 在“手动设置代理”里，找到“使用代理服务器”旁的编辑入口；不同版本可能显示“设置”或“编辑”。
  4. 确认这是自己使用客户端时留下的设置，且现在要恢复直接上网后，关闭“使用代理服务器”，并保存。
  5. 重新打开浏览器，再测试第一步选好的网站。

“自动检测设置”和“使用设置脚本”是其他选项，这次先保留原来的状态。公司或学校统一配置的电脑可能需要指定代理，遇到这种情况应按管理员的要求处理。微软 Windows 代理设置说明

如果关掉这个开关后恢复正常，说明原来的手动代理设置值得重点检查。下次需要使用客户端时，再从客户端中启用系统代理，不用凭印象重新填写地址和端口。

第四步：只有一个浏览器打不开，就检查它自己的设置

如果其他浏览器已经正常，只有 Firefox 仍然报连接错误，可以在 Firefox 设置里搜索“代理”，查看连接设置。

Firefox 可以跟随系统设置，也可以单独保存手动代理。如果你以前为它填过独立代理，现在希望它跟随已恢复的 Windows 设置，可以记录原配置后改为“使用系统代理设置”。页面若提示有扩展控制连接，还要检查对应扩展。Mozilla 连接设置说明

反过来，如果浏览器已经正常，只有命令行工具不能联网，可以接着看本站的浏览器能上网，命令行工具却连接失败，怎么查？，按具体软件继续排查。

开关关掉后又自动打开，接下来查什么？

先留意电脑里是否还有另一个代理客户端正在运行，或者某个客户端随开机自动启动。可以每次只退出一个自己认识的相关软件，再观察 Windows 代理开关有没有变化。这样比较，才容易找出是谁改了设置。

如果手动代理本来就是关闭的，或者关闭后仍没有改善，就不要把问题全部归到这个开关上。记录“哪些网站失败、哪些软件正常、重新打开客户端后是否恢复”，再对照客户端文档继续检查。求助时可以参考网络出问题怎么求助？发这几条信息就够了。

平时用完客户端，先关闭自己开启的代理功能，再正常退出。刚开始使用 Clash Verge Rev 的朋友，也可以对照本站基础设置教程，确认导入、启用和退出的顺序。
