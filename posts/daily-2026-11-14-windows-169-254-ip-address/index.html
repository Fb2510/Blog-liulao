Windows 出现 169.254 开头的 IP，为什么连上 Wi-Fi 也没网？

六佬2026-11-14— 次阅读
网络教程

**Windows 连上 Wi-Fi 却没网，正在使用的网卡又出现 169.254 开头的 IPv4 地址时，先检查自动获取地址是否成功。**在原本使用自动分配地址的家庭网络里，这通常表示电脑没能从网络拿到正常的 IPv4 配置。单凭这个数字，还不能判断是电脑、路由器还是中间连接出了问题。

IP 地址可以理解为设备在网络里的地址。DHCP 是自动分配地址的服务，家里通常由路由器提供。Windows 联系不到这项服务时，可能自行分配一个 169.254 开头的地址，这叫 APIPA，也就是自动私有地址。它可以用于同一局部网络里的有限通信，不能靠这个地址正常访问其他网段。微软对自动私有地址的说明

本文适合已经连上 Wi-Fi、但无法正常上网的 Windows 用户。排查顺序很简单：

  • 先看正在使用的网卡，确认地址没有看错。
  • 检查自动分配设置，再尝试重新获取地址。
  • 用另一台设备或手机热点做对照，缩小故障范围。

第一步：确认 169.254 属于哪张网卡

按下 Win + R，输入 cmd 并回车，在打开的命令提示符里输入：

ipconfig

它会列出电脑各个网络连接的 IP 地址、子网掩码和默认网关。默认网关可以理解为通往其他网络的出口，家庭网络里通常是路由器的地址。微软 ipconfig 命令说明

这次通过 Wi-Fi 联网，就找无线网络对应的一段；通过网线联网，就看正在使用的以太网连接。不要只看到列表里有一处 169.254，就认定整台电脑都出了同一个问题，虚拟网卡或另一张网卡也会出现在列表里。

重点记下两项：IPv4 地址和默认网关。例如，当前 Wi-Fi 显示 169.254.23.45，默认网关又是空白，就应继续检查它有没有成功获取地址。这里的数字只是示例，不要照着手动填写。

第二步：重新连接，核对自动分配设置

先关闭再打开电脑的 Wi-Fi，重新连接原来的网络，随后再运行一次 ipconfig。如果地址仍然一样，再检查设置。

以 Windows 11 为例，打开“设置 → 网络和 Internet → Wi-Fi → 管理已知网络”，选中这次连接的网络，找到“IP 分配”旁的“编辑”，查看是否为“自动（DHCP）”。微软的网络设置说明给出了这一入口，以及自动分配和手动设置的区别。Windows IP 分配设置

只有确认家里原本使用自动分配时，才把误设的手动地址改回自动，并先记下原设置。公司、学校或专门配置过固定地址的设备，应按网络管理员提供的设置处理。也不要把家人电脑上的 IP 地址原样抄过来，不同设备需要各自可用的地址。

第三步：尝试为这张网卡重新获取地址

如果已确认使用自动分配，可以在开始菜单搜索“命令提示符”，选择“以管理员身份运行”，执行一次：

ipconfig /renew "Wi-Fi"

上面的 Wi-Fi 要换成第 1 步里显示的实际连接名称，保留引号。例如连接名是“以太网”，就填写“以太网”。这条命令只适用于自动获取地址的连接，作用是重新申请 DHCP 配置。ipconfig 的 renew 参数

在电脑本机操作，并先暂停需要稳定网络的任务。命令执行完，再用 ipconfig 看地址和网关有没有变化。如果提示无法联系 DHCP 服务器或请求超时，记下原文，进入下一步做对照，不必连续重复输入命令。

第四步：用对照结果决定查哪里

先用手机连接同一个 Wi-Fi 测试网页，测试时暂时关闭手机移动数据，避免手机实际上借助移动网络上网。也可以让电脑连接手机热点做一次短暂测试，注意热点会使用手机流量。

对照结果 下一步优先检查
电脑连接手机热点能正常获取地址，回到家里 Wi-Fi 又出现 169.254 检查家中路由器的地址分配，以及电脑到路由器之间的连接
其他设备连接同一个 Wi-Fi 正常，只有这台电脑失败 先检查这台电脑的设置、无线连接记录及诊断结果
多台设备都无法自动获得正常的 IPv4 地址 优先检查负责分配地址的路由器及共同经过的设备

这些结果用于确定排查方向，不能单独证明某个硬件已经坏了。如果家里还有副路由或无线扩展器，可以再比较直连主路由 Wi-Fi 的结果，并记录哪一种连接方式出现问题。

管理自己的家用路由器时，按该型号的官方说明检查 DHCP 服务是否启用。微软也把这一项列为 169.254 地址问题的检查方向；Windows 11 用户还可以运行“获取帮助”应用中的网络和 Internet 疑难解答。微软 Wi-Fi 故障排查说明

常见问题

改 DNS 能把 169.254 修好吗？

DNS 主要负责把网址查成对应地址。当前连接连正常的 IPv4 配置都没拿到时，只改 DNS 无法代替 DHCP 分配地址。先完成上面的检查，再根据剩余症状处理其他问题。

地址变成 192.168 开头，就算完全修好了吗？

还要确认网关合理，并实际打开需要的网页。地址变化只是排查进展，不能证明外网连接已经恢复。如果问题发生在接入软路由之后，可继续对照软路由 WAN 和 LAN 同网段的检查方法。

仍然失败，求助时发什么？

提供 Windows 版本、当前联网方式、正在使用的网卡名称、IPv4 地址和默认网关，以及“家里 Wi-Fi 与手机热点”的对照结果。截图只保留有关部分，避免把账号、订阅链接等无关信息一起发出去。具体可参考网络出问题怎么求助。
