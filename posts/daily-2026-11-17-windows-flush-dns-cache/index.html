Windows 怎么清理 DNS 缓存？网页打不开时这样检查

六佬2026-11-17— 次阅读
网络教程

Windows 清理 DNS 缓存，可以在管理员命令提示符里执行 ipconfig /flushdns。它适合用来排查本机暂存的地址查询结果有问题的情况；命令执行成功后，还要重新访问原来的网页，才能知道这一步有没有帮助。

DNS 是把网站名称查成网络地址的服务，DNS 缓存就是电脑暂时记下的查询结果。你可以把它理解为一份临时通讯录。清理这份记录，不等于恢复整个网络，也无法修好网站服务器本身的故障。

先记住三个要点：

  • 核对网址和报错，确认是不是“找不到地址”一类问题。
  • 清理一次后，用同一个网址、同一个网络重新测试。
  • 没有变化就换排查方向，不必反复执行命令。

哪些情况适合先试清理 DNS 缓存？

例如，某个网站此前查询失败，现在网站方说已经恢复，但这台电脑仍提示找不到服务器地址，可以把本机缓存列为检查项。微软说明，/flushdns 会重置 DNS 客户端缓存，包括暂存的失败查询结果和动态加入的记录。微软 ipconfig 命令说明

不过，“网页打不开”只是表面现象。先花半分钟分清下面几种情况：

眼前的情况 优先做什么
刚复制的网址打不开 核对拼写，检查是否多了空格或标点
只有部分网站提示找不到服务器地址 记录报错，再尝试清理本机 DNS 缓存
Wi-Fi 根本没连上，或网线显示未连接 先恢复网络连接
网页能打开，只是图片或文字没更新 先检查网页刷新与浏览器缓存

如果属于最后一种情况，可以先看网页内容没更新时怎样检查缓存。网页文件缓存与 DNS 查询缓存用途不同，处理方法也不同。

第一步：打开管理员命令提示符

下面的命令适用于 Windows 11，也适用于仍在使用的 Windows 10。菜单文字可能因系统语言略有差别。

  1. 打开开始菜单，搜索“命令提示符”或 cmd。
  2. 在搜索结果中选择“以管理员身份运行”。
  3. 确认这是自己刚打开的系统工具，再接受系统提示。

如果是单位管理的电脑，没有相应权限就联系管理员处理。微软的网络排障说明也采用管理员命令提示符来执行缓存清理。微软网络排障说明

第二步：输入命令，再查看结果

把下面这一行输入到命令提示符，然后按回车：

ipconfig /flushdns

注意 ipconfig 后有一个空格，斜杠是 /。只复制这一行命令，不需要把代码框的边框或其他教程里的提示符一起复制。

看到表示 DNS 解析缓存已成功刷新的提示，就完成了这一步。不同系统语言显示的文字可能不同。如果出现权限不足或其他错误，先保留原始提示，确认是否以管理员身份打开，不要把报错当成清理成功。

这个操作清理的是本机的 DNS 查询缓存。它不会替你修改路由器，也不会替网站更新 DNS 记录。

第三步：重新打开原来的网页

保持当前网络不变，重新输入刚才出错的网址。必要时保存浏览器里未提交的内容，再退出并重新打开浏览器测试。先只改变这一项，才方便比较结果。

  • 能正常打开：记下这次操作和结果，先恢复使用；一次恢复还不足以证明以后遇到同样现象都是缓存问题。
  • 仍然报同样的错：核对网址，用另一台设备连接同一个网络试一下，再比较另一个浏览器的结果。
  • 报错换了内容：保存新的提示，按新问题继续查，不要只盯着原来的 DNS 报错。

用手机做同网对照时，确认手机确实在使用这条 Wi-Fi，避免它已经切到移动网络。对照结果能帮你缩小范围，但还不能单独判定哪台设备坏了。

清理后仍打不开，接着查哪里？

只有一个浏览器出问题

先看这个浏览器是否单独指定了查询服务。以 Chrome 为例，可在“设置 → 隐私与安全 → 安全”中查看“使用安全 DNS”。安全 DNS 就是通过加密连接查询地址。

Google 说明，自定义提供商出现查询问题时，也可能显示找不到服务器 IP 地址的错误。因此，只清理 Windows 缓存未必能改变浏览器的查询结果。先记录当前选项，核对自定义服务是否可用；若问题刚好发生在修改设置之后，可恢复刚改的那一项再比较。Chrome 安全 DNS 官方说明

想弄清这个选项的作用，可以接着看本站的安全 DNS 入门说明。

同一网络里的多台设备都失败

这时就需要检查大家共同使用的网络或查询服务，也可能是目标网站本身有问题。先比较其他常用网站能否打开，再查看路由器、运营商或目标网站的公告。清理一台电脑的缓存，处理不了所有设备共同遇到的故障。

电脑连正常的联网地址都没拿到

如果当前使用的网卡出现 169.254 开头的 IPv4 地址，可以按Windows 169.254 地址排查步骤先检查地址分配。DNS 查询需要可用的网络，缓存清理不能代替这一步。

常见问题

会删除浏览记录、保存的密码或 Wi-Fi 密码吗？

ipconfig /flushdns 的处理对象是 DNS 客户端缓存，不是浏览器历史记录、密码库或 Wi-Fi 连接配置。不要把它与浏览器的“清除所有数据”混在一起。

需要每天清理，网速才会快吗？

不需要把它当成日常加速操作。缓存本来就是为了减少重复查询，清理主要用于排障；下载速度、信号强度等问题，要根据实际症状另外检查。

清理 DNS 和“网络重置”是一回事吗？

不是。Windows 的网络重置会移除并重新安装网络适配器，将相关设置恢复为默认值，影响范围更大。微软把它列为其他办法无效后的最后步骤。只是想清理 DNS 缓存时，先使用上面这一条命令即可。微软对网络重置的说明

还要求助时，提供出错的网址、完整报错、清理命令的结果，以及同一网络下其他设备的对照情况。这些信息比“清过缓存还是不行”更容易让人接着排查。
