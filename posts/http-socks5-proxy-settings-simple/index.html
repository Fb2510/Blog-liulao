设置里选 HTTP 还是 SOCKS5？先把地址填对

六佬2026-11-05— 次阅读
网络教程

某个软件让你填代理，菜单里同时有 HTTP 和 SOCKS5。它们可以先理解为软件与代理入口交谈的不同方式。选哪个，首先取决于你要连接的入口支持哪一种。

客户端入口和外面的线路要分开看

客户端可能连着某种远端线路，同时给本机其他软件提供 HTTP 或 SOCKS5 入口。因此，不能看到机场宣传的一种连接方式，就直接在本地代理设置里选同名选项。

先打开客户端设置，找到它明确提供的入口类型、地址和端口，再填到需要联网的软件里。

三项要互相对应

类型选 HTTP，就使用支持 HTTP 的入口；类型选 SOCKS5，就使用对应的 SOCKS5 入口。地址和端口也要一并核对。如果客户端明确说明某个端口支持混合使用，再按它的说明操作。

配置示例里的 7890、1080 等数字并不是通用密码。每个人实际启用的端口可能不同，照着自己的客户端填写才有意义。

地址由谁查询，也可能不同

有些软件会区分“本机查网址地址”和“交给代理查”。例如 curl 中，socks5 与 socks5h 就有这种区别；带 h 的写法会把域名交给代理处理。curl 官方说明

普通用户不需要死记命令，但遇到一个方式能用、另一个提示找不到网站时，可以把这点作为检查方向。

别根据名字判断绝对快慢

选 HTTP 还是 SOCKS5，本身不能保证哪一种一定更快或更安全。先保证类型、地址、端口和认证资料都对应正确，再用实际需要访问的网站验证。连通之后，才有比较体验的基础。
